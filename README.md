# Bali Stay Collection (Airbnb-style Villa Booking Platform)

A curated collection of private villas across Bali — from romantic hideaways to family retreats and cliff-top sanctuaries. Built with React 19, Vite, and modern CSS.

> 📖 **Catatan Progres Lengkap & Panduan AI**: Silakan baca [`PROGRESS.md`](./PROGRESS.md) untuk detail lengkap seluruh arsitektur proyek, fitur yang telah diimplementasikan, aturan penulisan kode, data villa, dan rencana selanjutnya.

## Quick Start

1. Install dependensi:
   ```bash
   npm install
   ```

2. Jalankan server pengembangan lokal:
   ```bash
   npm run dev
   ```

3. Build untuk produksi:
   ```bash
   npm run build
   ```
